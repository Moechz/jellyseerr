# Changelog

All notable user-visible changes to the Jellyseerr TOS application package.

## 2.7.3-1 — 2026-11-11

### Added
- First release. Jellyseerr (`fallenbagel/jellyseerr:2.7.3`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8065 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/jellyseerrdocker/`.
